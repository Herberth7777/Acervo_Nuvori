# Acervo Nuvori

**Encontre sua próxima leitura. Baixe o arquivo. Leia no Nuvori.**

Este repositório foi criado para facilitar o acesso a livros, mangás e histórias em quadrinhos que possam ser distribuídos publicamente e lidos no aplicativo **Nuvori**. O catálogo é organizado por categoria, com informações de autoria, formato e download para cada obra disponível.

## Como baixar e ler

Quando houver obras disponíveis:

1. Escolha uma categoria e abra a ficha da obra.
2. Use o link **Baixar** para salvar o arquivo no seu aparelho. Não é necessário clonar este repositório.
3. No Nuvori, use a opção de importar um arquivo local e selecione o arquivo baixado.
4. Abra a obra na sua biblioteca e comece a leitura.

Confira o formato indicado na ficha e a compatibilidade com a versão do Nuvori instalada. Se encontrar um problema, informe o título, o formato e a versão do aplicativo ao entrar em contato.

## Autoria e distribuição

Cada obra terá sua autoria, origem e condições de distribuição informadas na própria ficha. A disponibilidade pública do repositório não altera os direitos sobre as obras. Serão aceitos conteúdos autorais autorizados, com licença que permita redistribuição ou com domínio público verificado para a edição disponibilizada.

Para propor uma obra ou solicitar uma correção, consulte [como contribuir](CONTRIBUTING.md) ou entre em contato pelo e-mail acima.
